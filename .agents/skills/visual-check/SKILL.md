# Visual Check

1. Abre la aplicación en 390x844 (móvil) y 1440x900 (escritorio).
2. Recorre los 5 pasos con perfil Novillero y perfil Ganadería comprobando mockups Canvas, Story 9:16 y aviso legal.
3. Inspecciona red y DOM asegurando cero errores de consola y ausencia del SVG limpio en el plan gratuito.
4. Verifica que ningún botón principal queda fuera del viewport y que no hay scroll horizontal.
